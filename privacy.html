Zinra

Privacy

Last updated: 18 August 2026

Zinra records a Chrome tab, a window, or a screen you choose, then edits and exports that recording on your computer. It is built to work offline after capture.

What Zinra accesses

  • Tab capture — Record this page records only the tab you start from, plus optional tab audio.
  • Screen / window / tab share — Record my screen uses Chrome’s picker. You choose a tab, a window, or the entire screen. Zinra does not learn which exact source you picked, only the type.
  • Camera — only if you turn on Include camera before recording. The webcam is recorded on your computer and composited into the export. Chrome asks you to allow the camera the first time.
  • Pointer position — sampled on a Chrome tab while a recording is armed, so zooms can follow clicks. That is always on for Record this page. For a shared tab or window it follows whichever Chrome tab has focus. Entire-screen shares do not sample the pointer. Sampling stops when you stop.
  • Downloads — to save the exported MP4 where you pick.
  • Sync storage — your preferences (zoom depth, quality, audio, camera). No recordings are uploaded.

What Zinra does not do

  • No account. No analytics SDK. No advertising ID.
  • Recordings are not sent to Zinra servers. Export runs in the extension window with WebCodecs.
  • Zinra does not read other tabs in the background. Capture and pointer sampling run only while you record.

Permissions

tabCapture, desktopCapture, tabs, activeTab, scripting, storage, and downloads exist so Zinra can record a tab or a screen you pick, place zooms, remember settings, and save a file. Host access is used only to inject the click-tracking helper on a tab you are filming. Camera uses the normal Chrome camera prompt, only when Include camera is on.

How automatic zoom uses pointer data

Auto zoom is a timeline of clips built from left-clicks and typing, not from pixels in the video. It runs on Record this page, and on a shared tab or window while you work in Chrome. It does not run on an entire-screen share. You can turn it off with “Mark a zoom on each click,” and you can edit or delete every clip after the fact.

Contact

For privacy questions, use the Chrome Web Store support email listed on the Zinra listing, or open an issue on GitHub.
